Client-side Script Injection

Đây là công cụ tiện ích cộng đồng do Honaki phát triển độc lập:

  1. Web hỗ trợ bạn tạo đường link chuyển hướng mở giao diện Poster của tài khoản trên trình duyệt.
  2. Đoạn Code Inject (Bookmarklet) sẽ chèn thêm giao diện tải ảnh tùy chỉnh vào webview.
  3. Khi bạn chọn và crop ảnh, script sẽ áp dụng trực tiếp lên layer nền của trang poster.

Công cụ phi chính thức: Dự án hoàn toàn độc lập, không thuộc quản lý và không liên kết với Garena hay Tencent/TiMi Studios.

Độ an toàn: Script chỉ chạy phía trình duyệt (Client-side Javascript), không can thiệp hay sửa đổi bất kỳ tệp tin cài đặt APK/IPA nào của game.

Không bao giờ. Mọi tác vụ phân tích file HAR, bóc tách token hoặc tạo URL đều xử lý trực tiếp trên trình duyệt của bạn. Hệ thống máy chủ không lưu trữ bất kỳ dữ liệu cá nhân hay file tải lên nào.
